Features

Live Leaderboard

6 datasets × 4 hardware tiers × 3 ranking metrics. Filter by CPU/GPU tier for fair comparison.

Drag & Drop Model Design

LiteGraph visual editor with 40+ node types. Build CNNs, ResNets, Transformers visually.

20 Achievements

First blood → SOTA Breaker (Legendary). Unlock with chime + toast notification.

ELO Rankings

6-tier system: Bronze → Silver → Gold → Platinum → Diamond → SOTA Champion.

Season System

30-day seasons with snapshot freeze, badge awards, and fresh leaderboard each cycle.

Daily Challenges

8 rotating constraint templates — new challenge every day. 'No Convolution', 'Speedrun', 'Tiny Model'...

Interactive Tutorial

Shadow puzzle placement guides you through building LeNet-5, CNN, and ResNet. Auto-fill after 30s idle.

Model Zoo

5 preset architectures with pre-built LiteGraph JSON. LeNet-5, ResNet, VGG, MLP, Transformer.
